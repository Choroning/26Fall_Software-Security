## 📝 레포지토리 소개

이 레포지토리에는 대학 수준의 소프트웨어보안 과목을 위해 작성된 이중 언어 학습 자료와 코드가 포함되어 있습니다:

- 각 강의자료마다 한국어(`.ko.md`)와 영어(`.md`)로 작성된 이중 언어 개념 정리 노트가 있습니다.
- 각 과제에는 솔루션과 함께 상세한 설명 문서가 포함되어 있습니다.
- 디렉토리는 강의자료 번호(`L01`, `L02` 등)를 기준으로 구성하며, 주차별 진도 표에 각 주차에 진행한 강의자료를 정리합니다.

> 본 과목은 프로그래밍 과제에서 AI 생성 코드 사용을 **금지**합니다.

- **🎯 강의 목표**

학생들은 다양한 연구 성과와 최신 보안 메커니즘을 통해 소프트웨어 보안 문제를 인식하고 그 해결책을 고안하는 능력을 기릅니다. 강조하는 주제는 메모리 안전성(Memory Safety), 타입 혼동(Type Confusion), 교차 언어 보안(Cross-Language Security), 지향성 및 하이브리드 퍼징(Directed & Hybrid Fuzzing), Rust 보안(Rust Security), 로봇 보안(Robot Security), 네트워크 프로토콜 보안(Network Protocol Security), LLM 보안(LLM Security)입니다.

- **📋 수업 운영 규정**

**출석**
- 출석은 LMS 스마트 출결 시스템(전자출결)으로 확인합니다. 어떤 이유로든 시스템이 작동하지 않으면, 수업 시작 시점에 (1) 시간, (2) 장소, (3) 본인이 모두 나온 셀카 한 장을 찍어 교수에게 이메일로 보냅니다.
- 전체 수업 시간의 3/4 이상을 출석해야 합니다. 그렇지 않으면 예외 없이 F 학점을 받으며, 자신의 출석 현황을 관리하는 것은 학생 본인의 책임입니다.
- 출석 상황에 따라 불시 출석 확인(예: 깜짝 퀴즈)을 할 수 있습니다. 전자출결상으로는 출석했지만 실제로 수업에 없는 학생에게는 상당한 불이익이 주어집니다.

**강의 홈페이지 (LMS)**
- LMS는 강의자료 다운로드, 과제 확인 및 제출, 각 과제의 점수 확인, 강의와 관련된 모든 질문에 사용합니다.

| 소통 | 규칙 |
|:-------------:|:-----|
| 하지 말 것 | 강의 내용, 과제 등 기술적인 질문을 교수나 조교에게 이메일, 전화, 카카오톡, 문자로 보내지 않습니다. 이러한 질문은 모두 LMS에서 학생들과 공유되어야 합니다. |
| 하지 말 것 | 소스 코드를 통째로 올리지 않습니다. 조교는 디버거가 아니므로, 버그를 대신 고쳐 주거나 코드를 일일이 읽으며 버그를 찾아 주지 않습니다. |
| 할 것 | 강의, 과제 등에 관한 기술적인 질문은 LMS에 올립니다. |
| 할 것 | 개인적인 사안은 교수나 조교에게 이메일로 연락합니다. |

**지각 제출**
- 가장 최근에 제출한 과제만 평가에 반영되므로, 이전 제출물에 확신이 있다면 다시 제출하지 않아야 합니다.

| 지연 시간 | 감점 |
|:------|:--------|
| 0시간 초과 24시간 이하 | 10% 감점 |
| 24시간 초과 48시간 이하 | 20% 감점 |
| 48시간 초과 72시간 이하 | 30% 감점 |
| 72시간 초과 | 제출 불가 |

**AI 생성 코드**
- 프로그래밍 과제에 ChatGPT, Copilot, Gemini 또는 이와 유사한 AI 모델을 사용하는 것은 허용되지 않으며, 사용 시 F 학점을 받습니다.
- 제출물은 외부 AI 생성 코드 탐지 솔루션으로 검사합니다.
- AI 생성 코드에 의존하는 학생은 아무것도 배우지 못하며, 시험을 통과할 수 없습니다.

**표절**

| | 규칙 |
|:-:|:-----|
| 하지 말 것 | 인터넷에서 코드를 복사하지 않습니다. |
| 하지 말 것 | 친구가 작성한 코드를 사용하지 않습니다. |
| 하지 말 것 | 다른 학생의 코드를 보고 아이디어를 얻지 않습니다. |
| 할 것 | 개념과 아이디어는 다른 사람과 토론합니다. |
| 할 것 | 조교와 교수에게 질문합니다. |

- 표절 규정에 따라 코드를 제공한 학생과 받은 학생 모두 F 학점을 받으며, 위원회에 회부됩니다.
- 코드 복제 탐지 솔루션을 사용하며, 예외는 없습니다.
